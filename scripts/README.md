# سكربتات تثبيت «شاشة» عبر ADB

`adb-setup.sh` (ماك ولينكس) و`adb-setup.bat` (ويندوز) يفعلان الشيء نفسه من حاسوب على شبكة الشاشة نفسها:

1. يتأكدان من وجود `adb`.
2. يتصلان بالشاشة عبر الشبكة (المنفذ 5555) وينتظران موافقتك على الشاشة حتى 60 ثانية.
3. يثبّتان ملف APK، أو يحدّثانه فوق النسخة الموجودة دون مسح بياناتها.
4. يمنحان ثلاث صلاحيات لا تُمنح إلا عبر ADB:
   - العرض فوق التطبيقات (`SYSTEM_ALERT_WINDOW`): ليغطي الحارس أي تطبيق آخر أثناء القفل.
   - الوصول إلى بيانات الاستخدام (`GET_USAGE_STATS`): ليعرف الحارس أي تطبيق في المقدمة.
   - تثبيت التطبيقات (`REQUEST_INSTALL_PACKAGES`): ليفتح زر «فحص التحديثات» مثبّت النظام.
5. يسألانك (y/N) إن كنت تريد تعطيل تطبيق يوتيوب الرسمي. الافتراضي: لا.
6. يشغّلان التطبيق ويعرضان التحقق من كل صلاحية وحالة خدمة الحارس، ثم ملخصاً.

لا يحذفان أي شيء من تلقاء نفسيهما.

## المتطلبات

- **Platform-Tools** من غوغل (فيه `adb`). فك الضغط بجانب السكربت فيصير عندك مجلد `platform-tools`، أو أضفه إلى PATH:
  - ويندوز: <https://dl.google.com/android/repository/platform-tools-latest-windows.zip>
  - ماك: <https://dl.google.com/android/repository/platform-tools-latest-darwin.zip> (أو `brew install --cask android-platform-tools`)
  - لينكس: <https://dl.google.com/android/repository/platform-tools-latest-linux.zip> (أو `sudo apt install adb`)
  - الصفحة الرسمية: <https://developer.android.com/tools/releases/platform-tools>
- ملف **`shasha-<الإصدار>-<الرقم>.apk`** من صفحة Releases في المستودع. ضعه بجانب السكربت: يُستخدم أحدث ملف
  `shasha-*.apk` بجانبه أو في المجلد الحالي إن لم تحدد المسار.

## تجهيز الشاشة (مرة واحدة)

1. **عنوان IP:** الإعدادات (Settings) > الشبكة والإنترنت (Network & Internet) > اسم شبكتك، ثم انزل إلى عنوان IP
   (مثل `192.168.1.50`).
2. **خيارات المطوّر:** الإعدادات > النظام (System) > حول (About)، ثم اضغط زر OK على «Android TV OS build»
   سبع مرات حتى تظهر رسالة «أصبحت مطوّراً».
3. **التصحيح:** الإعدادات > النظام > خيارات المطوّر (Developer options): فعّل «تصحيح أخطاء USB» (USB debugging)،
   و«تصحيح الأخطاء عبر الشبكة» (Network debugging) إن وُجد.

## التشغيل

```sh
# ماك / لينكس
bash adb-setup.sh 192.168.1.50
bash adb-setup.sh 192.168.1.50 ~/Downloads/shasha-0.1.0-1005.apk
```

```bat
:: ويندوز (أو انقر الملف مرتين واكتب العنوان، أو اسحب ملف APK فوقه)
adb-setup.bat 192.168.1.50
```

في أول اتصال تظهر على الشاشة نافذة «Allow USB debugging?»: فعّل «Always allow from this computer» ثم OK بالريموت.
في النهاية يجب أن ترى `[OK]` أمام الصلاحيات الثلاث. وللتأكد من داخل التطبيق: الإعدادات > حالة الحماية.
بعد الانتهاء يمكنك إيقاف «تصحيح أخطاء USB»؛ الصلاحيات تبقى.

**التحديث:** زر «فحص التحديثات» في التطبيق يكفي عادةً، أو أعد تشغيل السكربت بالملف الأحدث.
إن قال السكربت إن النسخة المثبّتة «موقّعة بمفتاح آخر» فلن يحذف شيئاً: يطبع أمر الحذف فقط. الحذف يمسح بيانات
التطبيق (الملفات والاشتراكات والسجل)، فصدّر نسخة احتياطية من إعدادات التطبيق أولاً.

## التراجع

```sh
bash adb-setup.sh --undo 192.168.1.50      # أو: adb-setup.bat --undo 192.168.1.50
```

يعيد تفعيل تطبيق يوتيوب الرسمي ويرجع الصلاحيات الثلاث إلى الوضع الافتراضي. التطبيق يبقى مثبّتاً؛ لحذفه
(يمسح بياناته): `adb uninstall com.ahmadnayfeh.shasha`. ولإعادة يوتيوب يدوياً:
`adb shell pm enable com.google.android.youtube.tv`.

## مشاكل شائعة

- **انتهت المهلة أو «unauthorized»:** تأكد من العنوان ومن أن الشاشة تعمل، ووافق على النافذة في الشاشة، ثم أعد
  التشغيل. إن استمرت المشكلة: `adb kill-server` ثم أعد المحاولة.
- **في خيارات المطوّر «تصحيح الأخطاء اللاسلكي» (Wireless debugging) بدل المنفذ 5555:** فعّله واختر «إقران الجهاز
  برمز»، ونفّذ `adb pair <IP>:<منفذ الإقران>` بالرمز الظاهر، ثم شغّل السكربت بالعنوان والمنفذ الظاهرين في تلك
  الشاشة، مثل `192.168.1.50:37215`.

القفل ليس منيعاً: من يصل إلى إعدادات الشاشة يستطيع سحب هذه الصلاحيات أو إعادة يوتيوب.
