# دليل استخدام «شاشة»

«شاشة» تطبيق يوتيوب خاص بتلفاز بيتنا: بلا إعلانات، وبلا اقتراحات، وبلا تسجيل دخول. فيه ملفات للأطفال لا يرون فيها إلا ما نسمح به، ووقت محدد للمشاهدة، وقفل للفيديو، وتحكم من الجوال.

هذا الدليل لكل أفراد البيت. كل فصل قصير، ومعه صور حقيقية من التطبيق.

> [!TIP]
> تريد نسخة للطباعة؟ **[كتيّب شاشة (PDF)](../Shasha-Catalog.pdf)** يجمع أهم ما هنا في صفحات مصمّمة.

## كيف تقرأ هذا الدليل

- **الكلمات العريضة** أزرار وعناصر تختارها على الشاشة، مثل **تحديث**.
- النص بين «» ما تكتبه الشاشة، مثل «انتهى الوقت».
- `OK` و`BACK` و`HOME` والأسهم `↑` `↓` `←` `→` أزرار الريموت.
- السهم ← بين الكلمات يعني «ثم»: الإعدادات ← **حول** تعني افتح الإعدادات، ثم اختر **حول**.
- في الصور المرقّمة، شرح كل رقم تحت الصورة مباشرة.
